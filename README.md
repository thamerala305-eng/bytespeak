# ByteSpeak | بايت سبيك

موقع مجاني لتعلّم إنجليزي التقنية خطوة بخطوة.

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا (Public) باسم `bytespeak`.
2. ارفع كل محتويات هذا المجلد (ومعها مجلد `b`). الرفع من المتصفح يقبل 100 ملف في المرة: ارفع الملفات على دفعتين.
3. Settings ← Pages ← Branch: `main` / root ← Save.
4. في `robots.txt` و `sitemap.xml` استبدل `YOUR-USERNAME` باسم حسابك.

## الظهور في Google
1. افتح https://search.google.com/search-console وأضف رابط موقعك (URL prefix).
2. اختر التحقق بـ HTML tag، وانسخ وسم meta، وأضفه في `index.html` داخل `<head>`.
3. بعد التحقق: Sitemaps ← أضف `sitemap.xml`، ثم URL Inspection ← Request indexing.
